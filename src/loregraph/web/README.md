# LoreGraph web

- **`landing/`** — the static **GitHub Pages** site (this is the product). Self-contained: React via CDN + plain CSS + JSX. The editable source runs with in-browser Babel; `build-landing.cjs` precompiles it into a production bundle.
- **FastAPI backend** (`server.py`, `routes/`, `schemas.py`) — an optional local query API, launched by `loregraph view`. Not part of the public static site.

## Preview locally

```bash
node serve-landing.cjs            # → http://localhost:4178 (source, Babel-in-browser)
```

## Build + publish to GitHub Pages

Live site: **https://yunyueli.github.io/LoreGraph/**

```bash
cd src/loregraph/web
npm install        # first time on a machine (esbuild + gh-pages)
npm run deploy     # build landing/ → dist/ (precompiled, prod React), then push to gh-pages
```

`npm run deploy` works from any fresh clone — `build-landing.cjs` builds, [`gh-pages`](https://www.npmjs.com/package/gh-pages) publishes via the repo's `origin` remote, so there's no branch or worktree to set up by hand.

> **Data.** The site reads pre-computed graphs from `landing/data-exports.js`, generated by `scripts/build_frontend_data.py` from `data/exports/*.json`. If the exports changed, regenerate it before `npm run deploy`.

### Cross-device workflow

1. `git clone git@github.com:YunyueLi/LoreGraph.git`
2. `cd LoreGraph/src/loregraph/web && npm install`
3. edit files under `./landing/`, then `npm run deploy`
